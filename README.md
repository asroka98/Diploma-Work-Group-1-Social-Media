# Diploma-Work-Group-1-Social-Media
"Wpływ aktywności w mediach społecznościowych na dobrostan psychiczny użytkowników – analiza wybranych czynników społecznych i zdrowotnych na podstawie danych ilościowych"

Q1: Jak ilość czasu spędzanego przed ekranem dziennie koreluje z subiektywną oceną poziomu szczęścia?
Analiza pozwala ocenić, czy intensywna aktywność online wpływa pozytywnie, negatywnie lub neutralnie na dobrostan psychiczny.​

Q2: Czy regularność aktywności fizycznej jest powiązana z wyższą jakością snu i niższym poziomem stresu wśród użytkowników mediów społecznościowych?
Pozwoli to ustalić, na ile ruch rekompensuje potencjalne negatywne skutki cyfrowego trybu życia.​

Q3: Czy rezygnacja z korzystania z mediów społecznościowych przez kilka dni skutkuje zauważalną poprawą samopoczucia (wskazanie zmian w takich zmiennych jak sen, stres, szczęście)?
To pytanie pozwala zweryfikować tezę o detoksie cyfrowym jako skutecznym narzędziu wsparcia psychicznego.​

Extra: Które cechy użytkowników (wiek, płeć, platforma) są najbardziej predyktywne dla poziomu szczęścia na podstawie modelu Machine Learning?
W tym zadaniu można zastosować klasyfikację albo regresję (np. Random Forest, SVM lub regresję liniową), by wskazać, które czynniki najlepiej przewidują szczęście na skali 1–10.
